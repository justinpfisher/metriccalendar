# Metric Calendar website

GitHub Pages static site for MetricCalendar.org.

## Files

- `index.html` — home/concept page
- `converter.html` — Gregorian ↔ Metric converter
- `rationale.html` — literature and rationale
- `faq.html` — FAQ
- `styles.css` — brand styling
- `script.js` — converter logic
- `CNAME` — custom domain configuration for GitHub Pages
- `robots.txt`
- `sitemap.xml`

## Asset folders

- `assets/logos/`
- `assets/favicons/`
- `assets/brand-reference/`

## Deployment

Upload the contents of this folder to the root of the GitHub repository.

In GitHub:
1. Go to Settings → Pages.
2. Publish from the `main` branch and repository root.
3. Set the custom domain to `metriccalendar.org`.
4. When available, enable Enforce HTTPS.

## Display rules

- Metric Calendar dates do not use a prefix: `2026-05-36`.
- Gregorian dates use a lowercase `g`: `g2026-07-01`.
- Use “metric month”, “metric week”, and “metric day”.
- Do not use unrelated time-system language.
