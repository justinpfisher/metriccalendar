# Metric Calendar website

Static GitHub Pages site for MetricCalendar.org.

## Files

- `index.html` — home/concept page
- `converter.html` — Gregorian ↔ Metric converter
- `rationale.html` — literature and rationale
- `faq.html` — FAQ
- `styles.css` — site styling
- `script.js` — converter logic and today’s Metric date
- `assets/logo.svg` — icon + wordmark
- `assets/logo-mark.svg` — standalone mark
- `assets/favicon.svg` — favicon
- `assets/calendar-model.svg` — annual model visual
- `CNAME` — custom domain for GitHub Pages

## GitHub Pages

Upload all files to the root of the repository. In GitHub Pages settings, publish from the root folder and use the custom domain `metriccalendar.org`.
