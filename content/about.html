Project background

Metric Calendar is a calendar framework attributed to J. Fisher / MetricCalendar.org. Its proposal combines a ten-month year with four Focus/Work Days and two Rest Days per metric week, plus extra days outside the regular metric weeks.

The project’s starting idea is to explore focused effort, predictable rest, and clearer planning. Its practical starting point is an organisational or personal planning overlay. Broader civil reform would require additional evidence, public discussion, and institutional coordination.

This site explains the rules, provides a date converter, examines relevant research, and describes questions a future evaluation would need to answer.

Use and attribution

The Metric Calendar framework is shared for common public use with attribution to:

J. Fisher / MetricCalendar.org

This is the project’s stated attribution for the framework. Third-party research remains the work of its respective authors and publishers. Citing a study here does not imply its authors endorse the proposal.

When describing the calendar, link to the specification. When discussing research findings, cite the original sources and distinguish them from claims about the Metric Calendar.

Scope and transparency

This is a proposal and reference website. It presents no documented Metric Calendar adoption figures, completed trials, independent evaluations, or institutional endorsements.

The calendar specification defines date arithmetic and day labels. It does not set employment terms, replace holiday rules, or guarantee outcomes. The limitations and adoption guidance explain those boundaries.

About the converter

Conversions run in your browser using the rules published on this site. Years 1–9999 are supported with Gregorian rules extended consistently across that range. Your device supplies the local date for “Today.” Dates are not sent to a separate conversion service.

This site does not add analytics or tracking cookies. Ordinary web hosting may receive request information; a converter link that you share includes its selected date in the URL.

Source code and corrections

The site and converter are maintained in the justinpfisher/metriccalendar GitHub repository. Its history records changes to the code and content.

To report a conversion problem, include the input date, conversion direction, expected result, and the result shown. For a content correction, identify the page and relevant primary source. View or open a repository issue (a GitHub account is needed to submit one).
